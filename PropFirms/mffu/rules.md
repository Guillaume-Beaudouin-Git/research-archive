## Key differentiator

- **Static (end-of-day) DD model** — does not trail intraday
- Typically more lenient than intraday trailing models like Tradeify
- No consistency rule (historical)

## Use case vs Tradeify

| Factor | MFFU | Tradeify |
|--------|------|----------|
| DD type | Static EOD | Intraday trailing |
| Intraday risk | Lower (EOD only) | Higher (intraday bust possible) |
| Consistency | None | YES (30%) |
| Cost (25K) | ⚠️ ~$150-200 | ⚠️ ~$170 |

Static EOD DD is more forgiving for high-volatility intraday strategies.
