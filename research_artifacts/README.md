## Methodology

Each folder contains:
- `deep_research.md` — full research report (AI-assisted literature survey +
  quantitative feasibility analysis, ~3000–8000 tokens)
- `VERDICT.md` — 1-page structured decision with academic references

### Gate sequence used

```
1. Regulatory/access check  → propfirm rules, geo-fencing, data cost
2. Breadth / IC feasibility → Fundamental Law, IJR gate, event-count [N_floor, N_ceiling]
3. Cost model               → RT costs vs gross alpha estimate
4. Regime stability         → sub-period IC breakdown, post-reform validity (L23)
5. Portfolio fit            → correlation with A+B+C, marginal Sharpe contribution
```

### Lessons applied

- **L7**: propfirm-rule compatibility verified before any other gate
- **L11b**: IJR formula corrections for binary TP/SL strategies
- **L12**: event-count ceiling gate (not just floor)
- **L15**: regime overlays produce sub-threshold lift on high-Sharpe portfolios
- **L23**: regulatory-window validity check for institutional microstructure edges
