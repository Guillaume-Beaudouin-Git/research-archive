## ⚠ Points d'attention infrastructure

### 1. Yahoo Finance bloqué dans l'environnement remote (CRITIQUE)

**Symptôme** : Toutes les requêtes `yfinance` → `HTTP 403: Host not in allowlist` pour
`query1.finance.yahoo.com` et `query2.finance.yahoo.com`.

**Impact** : Les handlers GenericHandler et RegimeFilterHandler tentent de charger des
prix via yfinance au niveau A. Quand les prix ne chargent pas (n_days=0), le baseline
Sharpe est NaN → FAIL_A automatique. Ces FAIL_A ne sont **pas** des conclusions statistiques.

**Items affectés** : Les 8 items dispatchés au GenericHandler comme TESTABLE_GENERIC +
`quantocracy_sharpe_ratio_of_pure_noise` (RegimeFilterHandler).

**Correctif** : Ajouter `query1.finance.yahoo.com` et `query2.finance.yahoo.com` à la
whitelist réseau de l'environnement remote. Alternative : utiliser les données locales
Binance (`data/raw/`) plutôt que yfinance pour les tests crypto dans le GenericHandler.
