## Critical finding: recurring silent infrastructure failure (yfinance network block)

This cloud execution environment has **no outbound network access to Yahoo Finance**
(confirmed directly: `yf.download('BTC-USD', ...)` → `ProxyError: curl 56, CONNECT tunnel
failed, response 403`). Every handler path that needs live price data
(`SkipMonthHandler`, `RegimeFilterHandler` fixed-threshold path, `GenericHandler`
`TESTABLE_GENERIC` category) calls `data/loaders.py::load_strategy_a_universe()`, which
silently swallows the per-ticker download exception, ends up with an empty price
DataFrame, and either raises `ValueError("No data loaded...")` (caught upstream) or
produces `n_days=0` / `Sharpe=n/a`. **The report templates for these handlers do not
surface this as an error** — they render it as a normal, science-looking negative
result (e.g. *"No regime overlay beats the Strategy A baseline... Consistent with L15"*
for a report where every metric table is blank and `n_days=0`).

exact same failure and recommends a fix (VPS execution, or a local-data fallback in
`data/loaders.py`). **That fix was never implemented.** Worse, the very next run that
hit this issue (`2026-07-02_run.md`) did **not** catch it — it accepted 14 `FAIL_A`
verdicts with the `n_days=0` / `n/a` Sharpe signature at face value and wrote a narrative
