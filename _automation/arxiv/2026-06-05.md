## [1] Dynamic Multi-Pair Trading Strategy in Cryptocurrency Markets with Deep Reinforcement Learning

**Authors** : Damian Lebiedź, Robert Ślepaczuk  
**Link** : https://arxiv.org/abs/2606.04574  
**Submitted** : 2026-06-03  
**Summary** : Évalue si un agent DRL (PPO+LSTM) améliore le pair trading classique dans les marchés
crypto très volatils. Introduit une sélection hiérarchique "Filter-then-Rank" des paires et un
modèle d'exécution "Fixed Risk, Adaptive Mean" avec shielding déterministe pour le risk management.
Validation hors-échantillon confirmée statistiquement au seuil 10% via circular block bootstrap
stationnaire sur données 1h Binance USD-M Futures. 61 pages, 37 figures.  
**Relevance** : Crypto futures (ecosystème Strategy B), méthodologie block bootstrap, paires
statistiques vs delta-neutral carry  
**Action** : READ

## [2] Anticipatory Portfolio Optimization

**Authors** : Miquel Noguer i Alonso (AIFI)  
**Link** : https://arxiv.org/abs/2606.04258  
**Submitted** : 2026-06-02  
**Summary** : Cadre théorique pour un portefeuille "anticipatoire" qui agit sur un modèle plus riche
qu'un estimateur myope. Trois types d'enrichissement : informationnel (filtration élargie), dynamique
(prévision des rendements/risques/coûts sur l'horizon de trading), performatif (loi d'impact de marché).
Mesure l'anticipation via le "control gap" réalisé entre contrôleur enrichi et estimateur restreint.  
**Relevance** : Portfolio optimization et vol targeting (Méthodologie — Strategy A ERC sizing)  
**Action** : READ
