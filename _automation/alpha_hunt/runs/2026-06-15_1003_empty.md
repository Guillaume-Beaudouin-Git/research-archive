## Note on architecture

The MD-generation routine is designed for cloud execution but depends on raw data
fetched by the VPS. Two options to fix this:

1. **Push raw files in a separate step**: Have the VPS cron run `process_raw_filter.py`
   locally to produce `_staging/*.json` files, commit those, and trigger the cloud
   routine only to do MD generation.
2. **Run the full pipeline on VPS**: Execute both the fetch and this routine directly
   on the VPS (requires Claude Code CLI on the VPS).
