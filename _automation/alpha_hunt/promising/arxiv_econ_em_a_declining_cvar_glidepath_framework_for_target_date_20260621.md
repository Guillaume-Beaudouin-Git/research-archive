## Summary
A Target-Date Fund design framework uses an explicit return objective with a CVaR constraint that declines as the target date approaches, formalizing the intuition that younger investors tolerate more tail risk. The optimal allocation converges to two-fund separation near the target date. Backtests over 1990-2024 show CVaR-constrained TDFs achieve comparable returns to age-based equity glide paths with 20-30% lower tail losses.
